# 動きのしくみ

[教材を開く](https://koji432.github.io/Energy_3D1114/)

1. メリーゴーランドの馬の上下運動、ティーカップの回転、てこクランクの揺動
2. 歯車、スライダクランク、カムと従動節、てこクランク。直接ドラッグ、ハンドル、スライダーによる手動操作
3. 車体から取り出す4気筒エンジンとチェキの透視・分解表示。燃焼からクランク、カム、バルブ、車軸へ伝わる連動と、モーターからフィルム送りローラーまでの歯車列
4. 自転車の変速。歯数やメーターを表示せず、歯車の大きさ、チェーンの移動、乗り手の動き、路面の流れで比較

各モデルをタップすると全画面で操作できます。操作はアイコンで表示します。

2・4ページ目はマウスやタッチで回します。手のアイコンで視点操作に切り替えられます。自転車は重いギアほど同じペダル回転までに大きなドラッグ量を必要とします。再生中は同じペダル回転数に対する車輪・路面の速さを比較できます。変速時は駆動部に寄り、ペダルを回しながらチェーンと変速機が移動し、元の視点へ戻ります。画面が物理的な抵抗を発生するものではなく、入力への反応による体感表現です。

ローカルでは `python3 -m http.server 8000` を実行し、ブラウザーで `http://localhost:8000/` を開きます。依存ライブラリは同梱しています。

## 参考資料

- [前作 Energy_3D1024](https://github.com/Koji432/Energy_3D1024)
- てこクランク — [広島大学の機構教材](https://www.hiroshima-u.ac.jp/system/files/76944/bulletin2016-8.pdf)。入力の連続回転を出力の往復する揺動に変換します。
- エンジンの模式モデル — [Continentalのタイミング駆動資料](https://www.continental-industry.com/getmedia/36b25bc5-80ed-4a71-acbb-f11f4d3978b2/PTG1107-En-Belts-and-Components.pdf)。直列4気筒、4ストローク、クランク2回転に対してカム1回転。内部観察のため外装を透視・断面化しています。
- チェキの模式モデル — [instax mini Evo Cinema の製品情報](https://www.fujifilm.com/jp/ja/news/list/13230)、[富士写真フイルムのフィルム送り機構の特許](https://patents.google.com/patent/US20020051636A1/en)。外観と機構の参照資料を組み合わせています。
- ローラー駆動 — [富士フイルムの歯車列の特許](https://patents.google.com/patent/US6356712B1/en)。モーター、複合歯車、中間歯車、ローラーの軸を接続し、フィルムの移動をローラーの外周速度と同期させています。歯数は教材用の模式値です。
- 変速 — [Shimanoの取扱説明書](https://si.shimano.com/en/pdfs/um/00C0A/UM-00C0A-003-ENG.pdf)、[Trekの変速説明](https://www.trekbikes.com/us/en_US/how-to-shift-gears/)。内部計算は前42歯、後ろ34・21・14歯。変速途中はチェーンの移動と回転比を補間しています。
