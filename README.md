# 動きのしくみ

[教材を開く](https://koji432.github.io/Energy_3D1114/)

1. 運動の種類 — メリーゴーランドの馬の上下運動、ティーカップの回転、車のワイパーの揺動
2. 歯車、4節リンク、カムと従動節。モデルの直接ドラッグ、ハンドル、スライダーによる手動操作
3. 車体のエンジンルームから取り出す4気筒エンジン、チェキのフィルム送り。透視・分解表示と機構ごとの強調
4. 自転車のギア比。前42歯、後ろ34・21・14歯の切り替え

各モデルをタップすると全画面で操作できます。操作はアイコンで表示します。

2・4ページ目はマウスやタッチで回します。手のアイコンで視点操作に切り替えられます。自転車は重いギアほど同じペダル回転までに大きなドラッグ量を必要とし、再生ボタンでは同じペダル回転数に対する車輪の速さを比較できます。力の表示は、同じ車輪負荷で必要となるペダルの力を34歯を基準に示します。画面が物理的な抵抗を発生するものではなく、入力への反応による体感表現です。

ローカルでは `python3 -m http.server 8000` を実行し、ブラウザーで `http://localhost:8000/` を開きます。依存ライブラリは同梱しています。
