# 動きのしくみ

[教材を開く](https://koji432.github.io/Energy_3D1114/)

1. メリーゴーランドの馬の上下運動、台とティーカップの回転、てこクランクで駆動する車のワイパー
2. 歯車、スライダクランク、てこクランク、カムと従動節。この順番で、直接ドラッグ、ハンドル、スライダーによる手動操作
3. 3Dプリントできる単気筒原動機、車でのピストンの使われ方、チェキのフィルム送り機構

各モデルをタップすると全画面で操作できます。操作はアイコンで表示します。

2ページ目はマウスやタッチで回します。手のアイコンで視点操作に切り替えられます。3ページ目は回転・拡大、分解、機構の色による選択ができます。自転車ページは削除しました。

ローカルでは `python3 -m http.server 8000` を実行し、ブラウザーで `http://localhost:8000/` を開きます。依存ライブラリは同梱しています。

## 原動機と実物の対応

これは作者の手回し式スライダクランク模型です。実物にない歯車、カム、バルブや燃焼表現は加えていません。クランク半径17 mm、連接棒の軸間約80.8843 mm、行程34 mmを元の軸穴から計測し、回転角に対して連接棒の長さが変わらない幾何計算で動かします。ピストン上死点で冠面が本体上端に一致します。

表示する組立位置は元の形状の軸穴、支持面と作者の完成写真から合わせています。印刷の収縮、ねじの締め込み量や個々の実物の隙間を再現するものではありません。STLそのものは変更せず、画面内で部品の配置・回転・表示色を設定しています。リンク機構はオレンジ、チェキの歯車は青、カムは紫です。

車のアイコンで実車の使用例に切り替わります。右上のピストンのアイコンで、エンジンを車体から取り出して拡大します。同じオレンジのピストンを手掛かりに模型と実車の対応を見比べられます。拡大時の点線と光は、取り出したエンジンと車内の動力経路の対応を示す図示です。分解時にはこの表示を消します。

検証: `node tests/printed-engine.mjs`。元のSTL上の軸穴を画面と同じ変換で追跡し、721姿勢で軸の接続、行程、上死点、部品数を確認します。車のカム・クランク・車輪の回転比も確認します。
